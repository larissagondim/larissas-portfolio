# Larissa Gondim — portfólio

Site pessoal bilíngue (pt/en) em Next.js, React 19, Tailwind 4 e next-intl.

```bash
cd portifolio
npm install
npm run dev     # desenvolvimento
npm run build   # build de produção
npm run lint
```

## Atualizando o conteúdo

- **Experiências:** `portifolio/data/experience.ts` (ordenadas automaticamente, mais recente primeiro).
- **Projetos, habilidades, formação, textos:** `portifolio/messages/{pt,en}.json`.
- **Cores e tipografia:** tokens em `portifolio/app/globals.css`.
